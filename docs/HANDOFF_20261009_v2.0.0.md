## 3. 남은 일

### 3-1. 바로 할 일 (1단계 마무리)
1. PC 에서 `bash tools/download_models.sh` → pyannote / FSMN 해시를 `app/src/main/assets/models.sha256` 에 채우기
2. Android Studio Gradle Sync·빌드(JitPack android-vad, JNA 5.17.0 해석 확인). 실패 시 JNA 를 5.16.0 으로
3. S25 Ultra 실기기: VAD 엔진 6종 × 짧은 음원 2~3개로 `[vad]` 로그·구간 수·CSV 확인
4. PC GUI 와 같은 음원으로 SILERO_* / PYANNOTE_* / FSMN_* / FIRERED_* 구간 비교(이식 정확도 확인)
5. FSMN 동적 일정 확인: PC `site-packages/funasr/models/fsmn_vad_streaming/model.py` 의 `DEFAULT_SILENCE_SCHEDULE`
6. push 여부 결정

### 3-2. 2단계 — sherpa-onnx STT 엔진
- AAR: GitHub Releases `sherpa-onnx-static-link-onnxruntime-<ver>.aar`(v1.13.7 기준, 공식 CI android-static.yaml 산출물) → `app/libs/`
- 엔진·모델(한/영, 상업 가능): Whisper tiny/base/small/medium(+turbo), Qwen3-ASR-0.6B int8, Omnilingual CTC 300M int8,
  Nemotron 3.5 ASR streaming 0.6B int8(80/160/560/1120 ms, `setOption("language","ko")`), Cohere Transcribe 2B int8(2.65 GB),
  Zipformer KO(offline/streaming, conditional), SenseVoiceSmall(conditional), Moonshine EN(MIT)/KO(conditional)
- 1회 최대 입력(엔진별 최대 길이 모드): Whisper 30 s, SenseVoice 30 s, Omnilingual 40 s 미만, Moonshine 기본 15 s, Cohere 예제 20 s,
  Qwen3-ASR·Zipformer offline 미명시(확인 필요), 스트리밍 엔진 제한 없음
- 모델 폴더(SAF) 선택 UI, 모델별 manifest(파일·SHA-256·라이선스)
- 두 ORT(앱 1.25.1 + sherpa 정적) 공존을 실기기에서 확인

### 3-3. 3단계
- Vosk small ko 0.22 / en-us 0.15 (`com.alphacephei:vosk-android:0.3.75`)
- iOS 확장은 별도 결정

## 4. 주의 사항
- ML Kit 은 실시간 공급만 공식 지원, SODA 세션 한도 약 35
- 10초 통일 + Google 엔진은 세션이 많이 든다(파일당 말 길이/10 s)
- 작업 환경(클라우드)은 Maven·Google 저장소 접속이 막혀 빌드 불가 → 빌드는 PC 에서
- 연결 폴더 기준 8단계 이상 깊은 파일은 파일 스테이징 도구로 못 읽는다(셸 도구는 가능)
