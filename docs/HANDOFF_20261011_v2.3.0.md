## 4. 남은 일

### 4-1. 바로 할 일
1. PC: `bash _apply_v2.3.0/apply_v2.3.0.sh` → `git push`(723a1bc·Q28·v2.3.0 커밋이 함께 올라간다)
2. 모델 받기: `bash tools/download_stt_models.sh nemotron3.5-320ms zipformer-ko zipformer-ko-stream sensevoice-small moonshine-tiny-ko`
3. Android Studio Run(2.3.0) → 각 모델로 kr 음원 실행 → Logcat `[D][sherpa]`·`[D][sherpa-stream]` 확인
4. Moonshine 이 실기기에서도 9 s 이하에서 정상인지(빈 결과 없음), SEG10 run_meta `stt_chunk_max_sec=9.0` 확인
5. 스트리밍 2종(Nemotron 320/560, Zipformer KO)의 `first_result_ms`·`tail_ms`·`feed_stall_ratio`, 메모리·발열 기록
6. PC 결과(SenseVoice·Nemotron 등)와 같은 음원으로 CER/WER 비교, VAD 켠 조건과 끈 조건 비교

## 5. 주의 사항
- **sherpa 결과 `text` 의 한국어 띄어쓰기**: 스트리밍(Nemotron·Zipformer)과 오프라인 Zipformer 는 지운다 → 토큰으로 만든다. Whisper·Qwen3·Omnilingual·SenseVoice·Moonshine 의 `text` 는 정상. 새 모델은 반드시 text 와 토큰을 비교할 것
- Moonshine tiny KO: 9.3 s 이상 조각에서 onnxruntime broadcast 오류(빈 결과). 상한을 올리지 말 것. 고정 절단에서는 반복 환각이 나올 수 있다
- Moonshine 토큰(tokens.txt)은 base64 라 토큰 이어 붙이기를 쓰면 안 된다(text 사용)
- 상업 사용: 4종 모두 조건부(README 7장). 회사 배포 판단 전 법무 확인
- 모델 폴더는 공용 `/sdcard/Documents/stt_models`('모든 파일 접근' 필요)
- 이 작업 환경: Google Maven·Maven Central·Gradle 배포·PyPI 막힘, GitHub 릴리스 내려받기 가능. Gradle 빌드는 PC 에서
- PC 연결 폴더에서 깊은 파일(8단계 이상)은 읽기 불가·쓰기 가능 → 크기 비교 + 적용 스크립트 내용 비교로 확인
- Kotlin 블록 주석 안에 `*/`·`/*` 금지
