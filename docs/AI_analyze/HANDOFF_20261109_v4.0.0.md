## 2. 남은 일

1. **LT-01 — 24시간 연속 실행.** 2026-11-09 에 시작했다가 배터리 2 %(PC USB 충전으로는 실행 중 방전)라 바로 멈췄다.
   폰에 설정이 남아 있다(입력 `input_sound/scarlett`, 출력 `output/lt1_check`, 모델 7 × VAD 22 × REALTIME = 242작업, 예상 3일).
   **벽 충전기에 연결**하고 충전된 뒤 앱에서 [실행] → [이어 하기]. 24시간이 지나면 [중지] → "이 작업 끝나고" 로 멈춰도 된다.
   확인할 것: 크래시 0, `_plan_exits.csv` 에 새 줄 없음, `_plan_memlog.csv` 의 `app_pss_mb` 가 계속 늘지 않음, 실패 0.
2. 화면을 끄고 30분 실행(MT-SVC-01)은 26분까지만 확인했다 — LT-01 로 함께 확인된다.
3. `v4-rewrite` → `main` 병합과 push(D27: 8단계 통과 후 병합). **사용자 확인이 필요하다.** `docs/baseline_v3/`(사용자 녹음의 전사문 포함)를 원격에 올릴지도 함께 정한다.
4. 릴리스 노트 docx 는 `python3 tools/md_to_docx.py docs/RELEASE_NOTES_v<판>.md` 로 만든다(python-docx). v4.0.0 docx 는 LibreOffice 로 PDF 변환해 3쪽 모두 눈으로 확인했고, 원문 글자가 빠짐없이 들어갔는지 대조했다. MS Word 에서는 열어 보지 않았다.

## 3. 결정 사항

- D1~D31: 02~06 문서와 `CLAUDE.md` 요약 그대로.
- 구현 중 정한 것(사용자 결정)
  - 옛 전사기·VAD 는 `git mv` 대신 새 파일로 이식하고 옛 파일은 T8-2 에서 삭제(2026-11-06).
  - Vosk 합격 기준은 "오류 없이 끝남 + 글자 수 > 0". 모델 파일(`mfcc.conf`)은 고치지 않는다(2026-11-06).
  - PC 평가기 중복 이름은 서버 쪽 엔진 이름 목록에 앱 엔진 이름을 더해 푼다(2026-11-07). **앱에 엔진을 더하면 서버 목록에도 더한다.**
  - Vosk 무너짐은 표시만 하고 재시도하지 않는다(2026-11-07, "권장 적용").
- 구현 중 정한 것(2026-11-09 "추천으로 모두 진행" 에 따라 추천안으로 반영)
  - `_summary.csv` 는 이어 하기 때 앞선 줄을 이어 쓴다.
  - 사용자 강제 종료·재설치는 충돌 횟수로 세지 않는다.
  - 공급 속도를 고른 작업의 소요는 예상 시간용 실측에 넣지 않는다.

## 4. 열린 문제

| 문제 | 상태 |
|---|---|
| LT-01 24시간 연속 실행 | 미실시 — 2장 1 |
| Vosk 한국어가 약 30회에 1회 무너짐 | 원인은 dither(확인). 표시는 붙는다. `--dither=0` 을 쓸지(모델 파일 수정 + 해시 검증과 충돌), 평가 때 어떻게 다룰지 미정. 앱 경로에서만 보인 이유는 가르지 못했다 |
| RT-02 Vosk | 영어 5 / 6 동일, 한국어는 실행마다 다름 — 사용자 판단 항목 |
| RT-05 서버와 조각 수 | VAD 뒤 길이는 일치. 조각 수는 같은 상한을 쓰는 서버 엔진이 없어 비교하지 못함 |
| ML Kit 영어 모델 | 시험 기기에 없어 영어 ML Kit 은 확인하지 못했다(한국어로 확인) |
| ML Kit 재시도 표시·세션 수 | `attempts` 항상 1, 세션 수를 작업마다 0 으로 돌림 — 4.0.x 후보 |
| 동시 2~3 에서의 충돌 판정 | 원인 작업을 가리지 못함 — 4.0.x 후보 |
| 화면에 없는 것 | 빠른 측정, 조합 CSV 불러오기, VAD 사용자 지정 값, 화면 회전 시 대화창 유지 |
| `WARN_NET_DELTA` 의 출처 | M4 에서 9건, 이후 실행에서는 0건. 설치 직후 첫 실행에서 잘 나온다. 무엇이 보내는지 미확인 |
| APK 안의 쓰지 않는 VAD 모델 4종 | `app/src/main/assets/` 의 로컬 파일(git 제외, 약 10 MB). 지우면 APK 가 준다 — 지우지 않았다 |
| 노이즈 저감 경로 | 단위 시험만 있고 실기기 실행은 하지 않았다 |
