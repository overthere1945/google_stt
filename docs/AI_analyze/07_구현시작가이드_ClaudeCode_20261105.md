## 2. 설치·로그인 (처음 한 번)
### 2-1. Claude Code 설치
```bash
curl -fsSL https://claude.ai/install.sh | bash   # 공식 네이티브 설치(Linux)
# 새 터미널을 열고
claude --version                                   # 판 번호와 "(Claude Code)" 가 나오면 성공
```
- `claude: command not found` 면 공식 문서 "Fix your PATH" 참고.

### 2-2. 회사망
- 필요한 주소: `api.anthropic.com`, `claude.ai`, `claude.com`, `platform.claude.com`, `downloads.claude.ai`(설치·자동 갱신).
- 회사 HTTPS 검사 인증서가 OS 인증서 저장소에 있으면 추가 설정 없이 동작한다. 아니면:
  ```bash
  export NODE_EXTRA_CA_CERTS=/path/to/company-root-ca.pem   # 회사 루트 인증서 경로
  ```
  (지속하려면 `~/.claude/settings.json` 의 `env` 에 넣는다.) 프록시가 있으면 `HTTPS_PROXY`.
- 회사 PC 에 설치해도 되는지는 사내 보안 규정을 먼저 확인한다.

### 2-3. 지침·규칙·권한 파일 복사
```bash
cd ~/workspace/AndroidStudioProjects/2026/google_stt
mkdir -p ~/.claude .claude/rules
cp docs/AI_analyze/claude_user_CLAUDE.md ~/.claude/CLAUDE.md                       # 개인 지침
cp docs/AI_analyze/claude_setup/rules/kotlin-code-rules.md .claude/rules/          # 코드 규칙(*.kt, *.kts 작업 때 로드)
cp docs/AI_analyze/claude_setup/settings.json .claude/settings.json                # 프로젝트 권한
```
- `.claude/` 는 원격 파일 도구로 쓸 수 없는 보호 위치라 이 대화에서 직접 만들지 못했다. 위 명령으로 복사한다.
- claude.ai 프로젝트 지침은 로컬 Claude Code 로 자동으로 넘어가지 않으므로 이 복사가 필요하다.

### 2-4. 로그인
```bash
cd ~/workspace/AndroidStudioProjects/2026/google_stt
claude          # 첫 실행 때 브라우저로 claude.ai 계정 로그인
```
- 들어간 뒤 `/context` 로 "Memory files" 에 `CLAUDE.md`(개인·프로젝트)가 보이는지 확인.

## 3. 휴대폰 연결
1. S24 Ultra: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 → 개발자 옵션 → **USB 디버깅** 켬.
2. USB 연결 → 휴대폰의 "USB 디버깅 허용" 수락.
3. PC: `adb devices` 에 기기가 `device` 로 보이면 준비 끝.
4. 장시간 실행 전: 3단계 문서 2-3 절차(배터리 "제한 없음", "절대 잠자지 않는 앱", 충전기 연결).

## 6. 진행 중 유의
- 권한 모드는 기본(묻기)으로 시작한다. `.claude/settings.json` 이 빌드·adb·커밋을 미리 허용하고 push·hard reset·서버 폴더 수정을 막는다.
- 휴대폰이나 브라우저에서 이어 보려면 세션 안에서 `/remote-control`.
- 컨텍스트가 길어지면 `/compact` 전에 CLAUDE.md 규칙대로 압축 정리 MD 를 먼저 남기게 한다.
- 마일스톤 보고 문서(`HANDOFF_*.md`)는 claude.ai 프로젝트에도 올려 두면 이 대화와 이어 볼 수 있다.
