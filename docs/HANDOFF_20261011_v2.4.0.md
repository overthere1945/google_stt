## 3. 2026-10-11 질문 답변 기록

### 3-1. Moonshine 9 s 제한이 arm64 에서도 같은가
- 오류는 sherpa 1.13.7 `offline-recognizer-moonshine-v2-impl.h` 의 디코더 실행 중 ONNX 그래프의 `Add` 노드 모양(shape) 불일치("Attempting to broadcast an axis by a dimension other than 1")다. 텐서 모양 규칙은 CPU 종류와 무관하므로 arm64 에서도 같을 가능성이 높다 — 다만 **실기기에서 확인한 것은 아니다**.
- 앱은 9 s 이하만 넣으므로 실기기에서는 이 오류가 나오지 않는 것이 정상. Logcat 에서 `Caught exception` / `chars=0` 이 없는지 확인한다.

### 3-2. 고정 길이 절단을 줄이는 VAD 프리셋
- 앱의 절단은 무작정 자르지 않는다: 상한보다 긴 말 구간만 상한의 50~100 % 구간에서 30 ms 에너지가 가장 작은 곳에서 자른다(`SegmentPacker`, PC split_long_segments 와 같은 규칙). 절단 횟수는 CSV `seg_splits`.
- 휴대폰 kr 음원 3개(customer·friend·vLog 01)의 에너지 근사 분석(실제 VAD 아님): 쉼 0.3 s 기준이면 최장 구간 7.2 s(9 s 초과 0개), 0.5 s 기준이면 vLog 에 9.3 s 1개, 0.8 s 이상이면 파일 전체가 한 구간(쉼이 0.6 s 에서 잘린 편집 음원).
- 그래서 Moonshine(9 s)은 쉼 기준이 짧은 프리셋(SILERO_USER 300 ms, SILERO_DEFAULT 100 ms, PYANNOTE_DEFAULT, FIRERED_DEFAULT)이 절단이 가장 적고, S500 계열(PYANNOTE_S500·FSMN_S500·FIRERED_S500)은 거의 없음, 긴 쉼 프리셋(SILERO_FW·SILERO_QWEN3·PYANNOTE_S2000·FIRERED_S2000·FSMN_DEFAULT/CONFIG)과 NOVAD 는 절단이 많다. Zipformer KO(15 s)·SenseVoice(30 s)는 S500 계열이면 충분하다.

## 4. 남은 일

### 4-1. 바로 할 일
1. PC: `bash _apply_v2.4.0/apply_v2.4.0.sh` → `git push`
2. Android Studio Gradle Sync(vosk-android 0.3.75·jna 5.18.1 받기) → Run
3. `bash tools/download_stt_models.sh vosk-small-ko vosk-small-en` (unzip 필요) → 휴대폰 `/sdcard/Documents/stt_models/vosk-model-small-*` 확인
4. Vosk small KO 로 kr 음원 실행 → Logcat `[D][vosk]`, CSV `first_result_ms`·`tail_ms`·`feed_stall_ratio`
5. TEN VAD 조건 결과가 JNA 5.17.0 때와 같은지 1회 확인
6. (선택) PC 의 `stt_models/vosk-model-small-ko-0.22` 가 생기면 Claude 가 그 폴더를 가져와 리눅스에서 VoskTranscriber 실음성 시험을 할 수 있다(리눅스 libvosk 0.3.45 + 시험용 바인딩)
7. 2-3 의 상업 조건부 4종·Nemotron 320 실기기 확인(HANDOFF v2.3.0 4-1)

### 4-2. 다음 단계

## 5. 주의 사항
- Vosk 모델은 언어별이고 폴더째 쓴다. 필수 파일 `am/final.mdl` + `conf/model.conf`(v2 배치). v1 배치 모델(final.mdl·mfcc.conf 가 맨 위)은 앱의 파일 점검을 통과하지 못한다
- 이 작업 환경: alphacephei.com·Maven Central·Hugging Face 접속 차단, GitHub(git clone·릴리스)은 가능 → Vosk 는 소스로만 컴파일 확인
- sherpa 결과 `text` 의 한국어 띄어쓰기 문제(스트리밍·오프라인 Zipformer)는 토큰으로 처리 중 — Vosk 는 Kaldi 단어 단위라 해당 없음
- PC 연결 폴더 깊은 파일(8단계 이상)은 읽기 불가·쓰기 가능
- Kotlin 블록 주석 안에 `*/`·`/*` 금지
