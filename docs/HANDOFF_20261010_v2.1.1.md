## 3. 남은 일

### 3-1. 바로 할 일 (2-1 마무리)
1. PC: `bash _apply_v2.1.1/apply_v2.1.1.sh` → `git push`
2. 휴대폰 정리: `adb shell rm -rf /sdcard/Android/data/com.example.google_stt/files/models`
3. `bash tools/download_stt_models.sh` → `/sdcard/Documents/stt_models/` 에 3개 패키지 확인(`adb shell ls -la /sdcard/Documents/stt_models/`)
4. Android Studio Run(2.1.1) → sherpa 모델로 START → '모든 파일 접근' 켜기 → 다시 START
5. Logcat `tag:GoogleStt message:[D]` 로 `dir report`(allFilesAccess=true, exists/canRead=true), `load done`, 조각별 `decode=…ms chars=…` 확인
6. whisper-base / qwen3asr-0.6b / omnilingual-300m × 짧은 음원 2~3개로 전사·CSV 확인, 두 onnxruntime 공존·메모리·발열 기록
7. PC 의 faster-whisper / qwen3-asr / omnilingual 결과와 같은 음원으로 WER/CER 비교

### 3-2. 2-2 — Nemotron 3.5 스트리밍, Cohere 2B
- Nemotron: OnlineRecognizer(transducer encoder/decoder/joiner + tokens), 패키지 `sherpa-onnx-nemotron-3.5-asr-streaming-0.6b-{80,160,560,1120}ms-int8-2026-06-11`,
  언어는 **OnlineStream.setOption("language", …)**. 값이 `ko` 인지 `ko-KR` 인지는 확인 필요
- Cohere Transcribe 2B: `OfflineCohereTranscribeModelConfig(encoder, decoder, language, usePunct, useItn)`, int8 약 2.65 GB
- 스트리밍은 Feed 설정(실시간 공급) 경로를 새로 만들어야 한다
- 새 모델도 `/sdcard/Documents/stt_models/<패키지>/` 규칙을 따른다

### 3-3. 2-3

## 4. 주의 사항
- **Android 11+ 에서 adb 로 `Android/data/<앱>` 안에 폴더를 만들면 앱이 그 폴더를 읽지 못할 수 있다**(이 휴대폰에서 실측). 앱 전용 폴더에 adb 로 넣는 방식은 쓰지 않는다
- '모든 파일 접근' 도 `Android/data` 는 열어 주지 않는다(공식 문서: `/Android/data/` 제외). 모델은 반드시 공용 폴더에 둔다
- sherpa 모델 파일이 없으면 배치를 시작하지 않는다(없는 파일로 네이티브를 부르면 앱이 통째로 죽는다)
- PC 에서 USB(MTP)로 결과 폴더를 보면 앱이 막 쓴 파일이 0바이트로 보일 수 있다 → `adb pull` 로 확인
- Kotlin 블록 주석 안에 `*/`·`/*` 금지(v2.0.0 빌드 오류 원인)
- sherpa AAR 판을 바꾸면 ABI 별 `.so` 구성을 다시 확인할 것(`unzip -l` + `readelf -d … | grep NEEDED`)
- `abiFilters` 는 네이티브 중복 오류를 막지 못한다(AGP 는 합치기 때 모든 ABI 중복 검사, abiFilters 는 패키징 때만) → `packaging.jniLibs.excludes`/`pickFirsts`
- 화면 로그(appendLog)는 원래부터 `GoogleStt` 태그 Log.i 로 Logcat 에 나간다. `[D]` 줄은 화면에 없는 정보만 더한다
- 이 작업 환경: Google Maven·Maven Central·Gradle 배포 서버 403(조직 정책) → Gradle 빌드 직접 불가. 컴파일 확인은 PC 의 jar/aar + Gradle 배포판 kotlin-compiler 2.0.21. PC 는 파일 읽기·쓰기만(명령 실행 도구 없음), 연결 폴더에서 8단계 이상 깊은 파일은 읽기(stage) 불가·쓰기는 가능
