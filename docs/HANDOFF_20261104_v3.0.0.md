## 3. 구현 요점
- `io/AudioInput.kt`
  - `INPUT_LANG_WORDS` / `inputLanguageHint()` / `planLanguageFolders()` 는 서버 `input_language_hint` / `_lang_folder_entries` 와 같은 규칙이다.
  - 입력 경로는 SAF `DocumentsContract.getTreeDocumentId()`(예: `primary:Documents/input_sound/kr`)로 받고, `/`·`\`·`:` 로 마디를 나눈다.
- `MainActivity`
  - `LANG_AUTO_POS = 2` 를 기본으로 고른다.
  - `runLanguageFolders()` 는 언어 폴더마다 `BatchRunner.run(BatchRequest(inSub = [폴더], outSub = [폴더]))` 를 차례로 부른다.
  - `langSequence` 가 켜져 있는 동안 `onBatchFinished()` 는 START 를 되살리지 않고, 끝에 한 번만 되살린다.
- `BatchRunner` 의 배치 본문은 그대로다. 목록 실행이 쓰던 `inSub` / `outSub` 길을 다시 썼다.
- `SherpaModels` / `SherpaOfflineTranscriber`
  - 계열 `ZIPFORMER_EN` / `NEMO_TRANSDUCER` / `MOONSHINE_V1` 을 추가했다.
  - 역할 `preprocessor` / `uncached_decoder` / `cached_decoder` 를 추가했다.
  - 설정 이름은 sherpa-onnx v1.13.8 `kotlin-api/OfflineRecognizer.kt` 와 대조했다.

## 4. 남은 일

### 4-1. 바로 할 일 (PC3·실기기)
1. PC3: `bash _apply_v3.0.0/apply_v3.0.0.sh`
   - 지운 파일 3개를 git 에서 지우고 v3.0.0 커밋을 만든다.
   - 스크립트가 파일 목록과 해시를 먼저 확인한다.
2. 빌드 준비(이 PC 는 v2 를 처음 빌드한다)
   - `bash tools/download_models.sh` 로 VAD 모델과 TEN `.so` 를 받는다.
   - `bash tools/download_stt_models.sh aar` 로 sherpa AAR 을 받는다.
3. Android Studio Gradle Sync → Rebuild → Run(S25 Ultra).
4. STT 모델 넣기(adb)
   - 기본: `bash tools/download_stt_models.sh`
   - 영어 4종: `… zipformer-en parakeet-tdt-0.6b-v2 moonshine-tiny-en moonshine-base-en`
5. 짧은 시험
   - 입력 = `Documents/input_sound`(kr·en), Lang = 폴더 이름으로 자동, Model = whisper-tiny, VAD = SILERO 로 돌린다.
   - `<출력>/en/whisper-tiny_sherpa-int8_SILERO/Customer_Service_EN/01.txt` 와 `<출력>/kr/…` 가 생기는지 본다.
   - 로그 `[lang]` 줄과, 끝난 뒤 START 가 되살아나는지 본다.
6. 영어 4종 실기기 시험: 속도·메모리·글자 확인. Parakeet 는 메모리를 특히 확인한다.
7. 확인되면 `git push origin feature/v3-app-server-align`. 사용자가 원하면 main 에 합친다.

### 4-2. 다음 단계

## 7. 독립 검토 (다른 에이전트, 코드만 보고 검토)
- 결함 없음
  - 컴파일·API: sherpa 설정 이름이 v1.13.8 Kotlin API·공식 예제 21·22·30 과 같다.
  - 지운 기호의 남은 참조: 코드·레이아웃·gradle·tools 에 없다.
  - 주석 안 `/*`·`*/`: 없다.
  - 다운로드 스크립트, 견본 616 작업, START·langSequence 처리, 서버 규칙·결과 구조: 모두 같다.
- 지적과 처리
  - **M1**: 음원이 없는 언어 폴더(예: 빈 `en`)가 '끝까지 못 돎' 으로 판정돼 뒤의 `kr` 까지 멈췄다.
    → 시작 전에 언어 폴더마다 음원이 있는지 보고, 없으면 건너뛴다(배치를 부르지 않음).
  - **L1**: 경로가 없는 문서 ID(다운로드 제공자 `msf:123` 등)로 `…/Download/kr` 를 고르면 언어를 못 찾았다.
    → 문서 ID 와 폴더 표시 이름을 함께 본다.
  - **L3**: 모두 건너뛰면 아무 알림이 없었다. → 토스트를 띄운다.
  - L2: [목록에 추가] 는 Lang 이 자동이면 거절한다. 목록은 줄마다 언어를 적어야 하므로 그대로 두고 문서에 적었다.
  - 그 밖: 지난 판 이력을 설명하는 주석의 'WebRTC'·'platform' 언급은 이력이라 남겼다. MainActivity 머리 주석은 '(삭제)' 로 고쳤다.
- 수정 뒤 다시 차등 컴파일했다. 새 오류 0건이다.
