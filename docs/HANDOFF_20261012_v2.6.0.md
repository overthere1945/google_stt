## 3. 구현 요점

- `plan/PlanState.kt`(새 파일): SharedPreferences `google_stt_plan` — in_uri·out_uri(권한 남아 있을 때만 되살림), workers, plan_running(commit), plan_in/out_uri(마지막 목록 폴더), last_exit_ts. `newExits()` = `getHistoricalProcessExitReasons(pkg, 0, 10)` 중 새 기록. `checkedThisProcess`(프로세스 단위 1회 점검).
- `PlanUi.checkResumeOnStart()`: 종료 기록 로그 → (실행 도중이었으면) `_plan_exits.csv` → `_plan.csv` 읽기 → prepare → 남은 작업이 있으면 창(실행 도중 꺼진 것이 아니고 FAILED 만 남았으면 로그만).
- `PlanRunner`: `run(…, workerCount)`, 시작 때 `_plan.csv`, 30초 `_plan_memlog.csv`("wa" 덧붙이기), 작업 전 `moveAsideOld`, DONE 이면 finally(NonCancellable)에서 `finalizeRunDir`(`_X → X`, "(1)" 이 붙으면 `_stale_` 로 되돌리고 FAILED).
- `BatchRequest.runDirPrefix` / `ResultStore.saveResult(…, dirPrefix)` — START 는 "" 로 예전과 같다.

## 4. 남은 일

### 4-1. 바로 할 일 (PC·실기기)
1. PC: `bash _apply_v2.6.0/apply_v2.6.0.sh` → Gradle Sync·Run → `git push`
2. 짧은 시험(kr, 작업 3~4개): 결과 폴더가 실행 중 `_…` 였다가 DONE 뒤 이름이 바뀌는지, `_plan.csv`·`_plan_memlog.csv` 가 생기는지
3. 이어 하기 시험: 실행 중 Android Studio 에서 앱 강제 종료(또는 `adb shell am kill`) → 다시 열기 → 이어 하기 창·`_plan_exits.csv`(이유는 USER_REQUESTED 등) 확인
4. 본 실행(견본 525 작업). 꺼지면 이어 하기 창 → 메모리 부족이면 줄여 이어 하기
5. Google 2종 개별 START(EPD A안, 입력을 35세션 안으로 나눠서)
