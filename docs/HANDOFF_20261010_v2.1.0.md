## 3. 남은 일

### 3-1. 바로 할 일 (2-1 마무리)
1. PC: `bash tools/download_stt_models.sh aar` → AAR 을 받은 뒤 **실제 AAR 로 컴파일 확인**(스텁으로만 확인했다)
2. Android Studio Gradle Sync → Rebuild → Run. 실패 시 Build 창의 `e:` 줄로 원인 확인
3. 앱 설치 상태에서 `bash tools/download_stt_models.sh` (기본 3종) → 휴대폰 앱 전용 폴더 확인
4. 실기기: whisper-base / qwen3asr-0.6b / omnilingual-300m × 짧은 음원 2~3개로 `[sherpa]` 로그(load ms)·전사·CSV 확인
5. 두 onnxruntime 공존(VAD Silero + sherpa 를 한 배치에서) 확인, 메모리·발열 기록
6. PC 의 faster-whisper / qwen3-asr / omnilingual 결과와 같은 음원으로 WER/CER 비교
7. 커밋 정리 후 PC 에서 push

### 3-2. 2-2 — Nemotron 3.5 스트리밍, Cohere 2B
- Nemotron: OnlineRecognizer(transducer encoder/decoder/joiner + tokens), 패키지 `sherpa-onnx-nemotron-3.5-asr-streaming-0.6b-{80,160,560,1120}ms-int8-2026-06-11`,
  언어는 **OnlineStream.setOption("language", …)**(Kotlin OnlineStream 에 setOption 있음 확인). 값이 `ko` 인지 `ko-KR` 인지는 확인 필요
- Cohere Transcribe 2B: `OfflineCohereTranscribeModelConfig(encoder, decoder, language, usePunct, useItn)`, int8 약 2.65 GB
- 스트리밍은 Feed 설정(실시간 공급) 경로를 새로 만들어야 한다

### 3-3. 2-3
- Zipformer KO(offline/streaming), SenseVoiceSmall, Moonshine KO — `commercial=conditional` 표시
- Vosk small ko 0.22 / en-us 0.15 (`com.alphacephei:vosk-android:0.3.75`)

## 4. 주의 사항
- sherpa 모델 파일이 없으면 배치를 시작하지 않는다(없는 파일로 네이티브를 부르면 앱이 통째로 죽는다)
- 휴대폰 모델은 앱을 지우면 함께 지워진다(Run 덮어 설치는 유지)
- PC 에서 USB(MTP)로 결과 폴더를 보면 앱이 막 쓴 파일이 0바이트로 보일 수 있다 → `adb pull` 로 확인
- Kotlin 블록 주석 안에 `*/`·`/*` 금지(v2.0.0 빌드 오류 원인)
- 이 작업 환경은 Maven·GitHub 다운로드가 막혀 있다. 컴파일 확인은 PC 의 jar/aar 를 읽어 Gradle 배포판의 kotlin-compiler 2.0.21 로 한다
